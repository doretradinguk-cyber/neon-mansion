# Firefly art handoff

Use this folder for Firefly prompts, visual references and notes for generated Neon Mansion assets.

Primary uses:
- replacement wall / floor / wood / metal texture concepts
- neon glow and emissive overlays
- Nightmare Frequency code-rain overlays
- stained-glass and window background concepts
- room backdrops and distant exterior vistas
- decals, signage and holographic elements
- concept boards for Entrance Hall, Long Gallery and later rooms

Generated images should be cleaned and prepared in Photoshop before being treated as game-ready runtime assets.
